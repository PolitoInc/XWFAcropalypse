Acropalypse (CVE-2023-21036) is a security vulnerability in the Google Pixel Markup tool and Windows Snip & Sketch that allows for the recovery of cropped or edited-out data from PNG screenshots. 
Discovered in 2023, it enables attackers to reconstruct original images, potentially exposing+ sensitive, unseen information, even if the user saved over the original file 
This X-Ways Forensics (XWF) extension detects image files with this vulnearbility and marks the files as "notable".
